# A1 Tokyo Reference End-to-End Pilot

This directory will record the first small-area A1 Tokyo Reference end-to-end
experiment. The planned flow is:

```text
Tokyo data
→ input preparation
→ VoxCity
→ 3D model
→ B1 Solar / Shade
→ B2 360° GVI (Canopy)
→ GIS outputs
```

This is planned work only. No input selection, workflow, analysis, or output is
implemented here yet; fixing the pilot site and input datasets belongs to the
future E2E-0 task.
