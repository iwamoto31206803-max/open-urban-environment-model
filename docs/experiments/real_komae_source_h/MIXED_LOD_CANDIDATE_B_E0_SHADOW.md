# Candidate B E0 VoxCity日陰機能確認

**E0-B PASS（Windows CPU、合成モデル）**。OUEM venvのインストール済みVoxCity 1.7.0と `direct_url.json` のcommit `fa212656305328a9a657973bae26f352bfe813bc` をテストで確認した。E1の実データ計算は未実施。

## E0-A ソース確認

コード位置は固定版の `voxcity/` 配下。

| 位置 | 確認内容 |
|---|---|
| `simulator/solar/kernels.py:11–84` | 3Dクラス配列から水平2Dの透過率を返す。T5では0=空気、−1=地中、1=表面、−3=建物（−2は樹木、今回なし）。有効な無樹冠ケースは1=日向、0=遮蔽。 |
| `utils/orientation.py:72–105` | 方位角は北起点で時計回り、高度角は水平面から上向き。返すベクトル成分はaxis 0が北、axis 1が東、axis 2が上。観測点から太陽へ向けるため、太陽が南なら軸0は負。反転した180°を加えない。回転付き格子では回転角を差し引く。 |
| `simulator/common/raytracing.py:12–131` | 光線は指定した開始ボクセルの中心から進む。exclusion modeでは許可集合外の非TREEが遮る。許可 `(0,)` では地中・表面・建物が遮蔽物、`(0,-1,1)` ではT5のクラス集合のうち建物だけが遮蔽物。領域外へ出ると遮蔽なしとして終了する。開始点が配列外の場合も同様。 |
| `simulator/solar/radiation.py:18–65` | 公開ラッパーはVoxCityオブジェクトを要求し、空気のみを許可して透過率にDNIと高度角の正弦を掛ける。描画はオプション。二値日陰には低水準関数を直接使用する。 |
| `simulator/solar/temporal.py:30–46` | Astralの方位・高度を緯度経度と時刻から計算し、pandas DataFrameを返す。E0では時刻変換を実行していない。 |

屋根除外モードは、下から最初の固体→空気／TREE遷移を評価する。直下が負クラスまたは水クラス7–9の場合と、遷移が無い場合はNaN。屋根有効モードは上から探索し、−3の屋根を許容する。地上に空洞がある建物では下側の表面を先に拾う可能性があるため、E1では建物列を明示的に除外する。開始位置は遷移の空気側添字に `int(view_point_height/meshsize)` を加えたボクセル中心。0 m指定でも固体面の直上の空気セル中心となる。

核の直接依存はNumPy・Numba。方位変換はNumPy、日時変換はAstralとpandas、公開ラッパーの描画にはMatplotlibが関与する。インストール済み配布物のMETADATAとLICENSEはMIT。CPU核の実行にGPUや外部データを必要としなかった。

## E0-B 実測と再現

合成入力はint8の19×23×12、1 m。地中k=0、表面k=1、建物は `[7:10,11:15,2:6]` の4 m直方体。独立した幾何の期待値は連続空間の固体面で `4/tan(45°)=4 m`。最初の空気中心から45°で水平・鉛直を同時に1セル進むため、建物に入る高さk=3〜5に対応する離散影は3列と予測した。

| 条件 | 日陰／日向／NaN | 観測 |
|---|---:|---|
| 南180°、45°、0 m | 12／413／12 | 北に3列 |
| 東90°、45°、0 m | 9／416／12 | 西に3列 |
| 建物なし | 0／437／0 | 全セル日向 |
| 屋根有効 | 12／425／0 | 12屋根セルは日向。屋根無効時はNaN |
| 南、1 m・1.5 m | 各8／417／12 | 同一マップ、北に2列 |
| 境界 | 観測点0→1 | 上流の遮蔽物を除く切り出しで日陰から日向に変化 |
| 盛土地盤 | 観測点0→1 | 地盤クラスを光線の許可集合に加えると日向 |

水、露出した地中、表面なしの3列はNaN。高さ12 mで開始点が配列上限を越えると通常の地表列は日向になり、屋根除外のNaNは残った。E1は範囲外開始を事前に拒否する。
